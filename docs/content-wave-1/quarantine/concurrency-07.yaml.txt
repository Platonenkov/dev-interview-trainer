    answer: "1 2 3 count=4"
    explanation: |
      The documentation of `ConcurrentQueue<T>.GetEnumerator` says the enumeration is a moment-in-time snapshot of the
      queue taken when `GetEnumerator` is called: it does not reflect later updates, and it is safe to use concurrently
      with reads from and writes to the queue. `foreach` calls `GetEnumerator` before the first iteration, when the queue
      holds `1`, `2` and `3`. So `Enqueue(4)` inside the loop neither breaks the enumeration nor extends it: `1 2 3` is printed.

      and from `ConcurrentDictionary<TKey, TValue>`, whose enumerator is also safe during concurrent writes but is not
